# セキュリティ監査・対策結果（2026-10-29）

旧版の配布保留を受け、実行環境・依存関係・通信・入力・保存・配布内容を見直した対策版です。**対策後にインストールした46パッケージをOSVへ照合し、該当する既知アドバイザリは0件でした。** 照会日時と全バージョンは [機械可読の監査記録](examples/security-audit.json) に収録しています。照合にはパッケージ名とバージョンのみを送信しました。

## 発見事項と対策

| 発見事項 | 対策版の処置・確認 |
|---|---|
| langchain-core 0.2.43、langgraph 0.2.14、checkpoint 1.0.12、langsmith 0.1.147、pypdf 4.3.1、pip 25.0.1に既知の該当あり | core 1.7.1、graph 1.2.18、checkpoint 4.3.1、langsmith 0.14.14、pypdf 6.21.4、pip 26.2.2を含む全依存を更新・固定。新環境を全件再照合 |
| Python 3.12.14／OpenSSL 3.5.8が旧版 | 専用環境をPython 3.14.10／OpenSSL 3.5.9へ更新。起動時に最低版を確認 |
| URLや環境プロキシ経由でキー・質問が意図しない宛先へ送られる余地 | 公式OpenRouter HTTPSとループバックLM Studioへ限定。ユーザー情報・クエリ付きURL拒否、プロキシ環境変数とリダイレクトを無効化 |
| キーや応答本文がエラー・ログへ混入する余地 | SecretStr、キーのマスキング、APIエラー本文を表示しない。調査用の本文ログは初期設定で保存し、GUIまたは設定で無効化できる。ログ共有前の内容確認を案内 |
| 環境変数で有効なLangSmithトレース | グラフ実行を tracing_context(enabled=False) で囲み、外部トレース送信を無効化 |
| モデル出力の任意ツール名・不正な引数 | 検索2種類の許可リスト、1回最大2呼び出し、重複ID・余分な引数・長過ぎる検索語を実行前に拒否。モデルによるシェル実行・任意ファイル操作機能はない |
| 巨大なAPI応答・検索キャッシュ・差し替えPDF | 応答8MiB上限、圧縮応答拒否、JSON・ベクトルの型／サイズ制限、有限値確認。書籍3ファイルをSHA256確認後にPDF解析 |
| 書き込み先の逸脱・中断時の不完全キャッシュ | 作業ルート境界とフォルダーのリンク／ジャンクションを確認。インデックスを一時ファイルから置換、実行ログを排他的に新規作成 |
| 配布に個人ログや旧依存が混入する余地 | requirementsを全依存＋SHA256で固定。配布対象は明示リスト。ZIPにファイル一覧とSHA256を同梱し、設定本体・環境・作業ログを除外 |

旧監査は36パッケージ中6パッケージに該当がありました。GHSAとPYSECなどの別名があるため、アドバイザリの記録数を独立した脆弱性の件数として扱っていません。LangChainのシリアライズ関連は重大度Criticalのものを含みました。ただし、このアプリから全件が実際に悪用可能かの実証は行っていません。

## 確認範囲と残る注意点

OSV照合はその時点の既知情報です。未登録の脆弱性や将来の発見がないことを保証しません。Windows、LM Studio本体、モデルファイル、GPUドライバー、他章や旧 `.venv` の安全性は今回の監査対象外です。既存の共有Python環境を変更せず、この配布版用の新しい環境を作っています。

保存先のチェックは、同一OSユーザーによる悪意ある同時ファイル差し替えを防ぐ隔離環境ではありません。自分が管理できるフォルダーで使ってください。資料のハッシュはZIPに含めた既知資料との照合であり、配布者のデジタル署名ではありません。

モデルは検索文書内の指示に影響され得ます。実行可能な操作を検索に限定しましたが、回答の正確性やプロンプトインジェクションへの完全な耐性は保証しません。モデルの自己評価がOKでも出典を確認してください。勉強会では付属の架空システム資料と質問例を使います。

OpenRouter実接続はユーザーの指定により未実施です。OpenRouter利用時は質問・検索文書が外部へ送られます。料金ゼロの指定と無料モデルの制限は設けていますが、サービスの無料提供状況・利用条件は開催前に確認が必要です。
